# CodefinityTestTask
A small iOS sample app that demonstrates a chapter-based audio summary experience built with the Composable Architecture (TCA). The app loads a Book with chapters, displays a summary UI, and connects chapter audio playback to a local AudioPlayer feature.

Key features
- Fetches a Book and its chapters and shows chapter metadata
- Per-chapter audio playback with play/pause, seek, speed, and chapter navigation
- UI built with SwiftUI and application state managed using the Composable Architecture
- Test targets and a Fastlane action for running unit tests

Tools
- SwiftUI
- TCA
- Swift Testing
- Fastlane
